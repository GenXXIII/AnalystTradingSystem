# Signals

Phase 12 owns deterministic local signal lifecycle only: `NOTHING`, `BUY`, `SELL`, and `STOP`.

The local analyst uses completed XAUUSD candles and application-owned technical analysis. It records a public market signal identifier, the origin candle, deterministic conditions, updates, and terminal reason without calling AI or creating an order. Target, Full, predictive, execution, and notification workflows remain outside this boundary.
